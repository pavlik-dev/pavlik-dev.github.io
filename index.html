Peachy theme

A pretty theme featuring peachy sky with clouds.
Available for both new and old versions of Chrome, and modern versions of Firefox. (not the old ones with XUL-based themes, sry i tried)

To install on Chrome, first download the theme as a file by right-clicking the version you want and selecting "Save link as...".
Then go to chrome://extensions, enable Developer mode and drag and drop .crx file into the browser window.

IDv3dit

IDv3dit is a simple web-based ID3 tag editor for MP3 files.
Not only can it do title, album, artist, but also can automatically add lyrics (either unsynced or both synced and unsynced from a LRC or SRT file), auto converts album art to JPG, and so much more!
